NOMBRE DEL PROGRAMA: Sistema de Gestión de Reservaciones (Estructura MVC Simulada)

DESCRIPCIÓN:
Este programa gestiona las reservaciones de un restaurante a través de un menú de consola. Para reflejar la estructura de la aplicación original en Java, el pseudocódigo está organizado para simular un patrón de diseño Modelo-Vista-Controlador (MVC).
-   El MODELO contiene los datos (los arreglos de reservaciones).
-   La VISTA maneja toda la interacción con el usuario (mostrar menús, mensajes, etc.).
-   El CONTROLADOR contiene la lógica de la aplicación (qué hacer cuando el usuario elige una opción).

ALGORITMO:
1.  INICIO DEL PROGRAMA (Proceso Principal).

2.  SECCIÓN DEL MODELO:
    -   Se definen los arreglos paralelos (nombres, celulares, dias, horas) que funcionarán como el almacenamiento de datos de las reservaciones.
    -   Se define la variable `num_reservaciones` que controla el tamaño actual de los datos.

3.  PUNTO DE ENTRADA DE LA APLICACIÓN:
    -   Se llama a una función del CONTROLADOR (`Controlador_CargarReservaciones`) para llenar el Modelo con los datos del archivo "reservaciones.txt".

4.  CICLO PRINCIPAL (Bucle `Repetir...Hasta Que`):
    -   El bucle se ejecuta hasta que el usuario elige la opción de salir (5).
    -   En cada iteración:
        a. Se llama a una función de la VISTA (`Vista_MostrarMenu`) para mostrar las opciones y obtener la elección del usuario.
        b. Se llama a una función principal del CONTROLADOR (`Controlador_ManejarOpcion`), pasándole la opción del usuario y los datos del Modelo.

5.  SECCIÓN DEL CONTROLADOR (Lógica de negocio):
    -   `Controlador_ManejarOpcion`: Actúa como un enrutador. Utiliza una estructura `Segun` para llamar a otras funciones del Controlador o la Vista basándose en la opción del usuario.
    -   `Controlador_AgregarReservacion`:
        -   Verifica si hay capacidad.
        -   Llama a la VISTA (`Vista_PedirDatosReservacion`) para obtener los datos del usuario.
        -   Actualiza el MODELO (los arreglos) con la nueva información.
        -   Llama a la VISTA (`Vista_MostrarMensajeExito`) para notificar al usuario.
    -   `Controlador_ModificarReservacion`:
        -   Llama a la VISTA para mostrar las reservaciones actuales.
        -   Pide al usuario el celular a buscar.
        -   Llama a una función auxiliar (`Controlador_BuscarPorCelular`) para encontrar el índice en el MODELO.
        -   Si lo encuentra, pide los nuevos datos y actualiza el MODELO.
    -   `Controlador_CancelarReservacion`:
        -   Funciona de manera similar a modificar, pero una vez encontrado y confirmado, reorganiza el MODELO para eliminar el registro.
    -   `Controlador_GuardarReservaciones`:
        -   Abre "reservaciones.txt" y escribe el contenido actual del MODELO en el archivo.

6.  SECCIÓN DE LA VISTA (Interacción con el usuario):
    -   Contiene todas las funciones que escriben en la consola o leen datos del teclado.
    -   Estas funciones NO contienen lógica de negocio. Solo muestran información o la solicitan. Por ejemplo, `Vista_ListarReservaciones` solo muestra los datos que recibe; no sabe de dónde vienen.

7.  FIN DEL PROGRAMA:
    -   Cuando el usuario elige salir, el bucle termina y el programa finaliza.
